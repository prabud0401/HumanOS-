# Skill: Knowledge Management

## When to use
When organizing, storing, or retrieving knowledge and memories.

## Procedures

### Storing a new memory
1. Determine the memory type: episodic, semantic, procedural, or emotional
2. Write a clear, searchable title
3. Write the content with enough context to be useful later
4. Add relevant tags (comma-separated)
5. Rate importance (1-10)
6. Save to the memory store

### Searching memories
1. Parse the search query for key concepts
2. Search by title, content, and tags
3. Rank results by relevance and importance
4. Return the most relevant memories with context about when they were stored

### Connecting knowledge
When you find related memories:
1. Mention the connection explicitly
2. Explain how the current topic relates to past knowledge
3. Suggest implications or insights from the connection

### Knowledge hygiene
- Avoid storing duplicate information
- Update existing memories when new information supersedes old
- Periodically flag low-importance old memories for review
